# Security & publication review

This is a **fresh public portfolio copy**, constructed from local synthetic-data demos rather than a clone of the original private Git repository. The package contains **no `.git` directory and no inherited commit history**.

## Included

- Only two re-exported demo workflows with manual triggers; one includes read-only test Sheets input and three Gmail nodes **disabled**.
- Only fictitious applicants with `example.com` email addresses.
- A screenshot showing the successful three-branch local execution and deactivated Gmail nodes.

## Removed or replaced for public sharing

- Personal Gmail address → `YOUR_TEST_INBOX@example.com` (all Gmail nodes disabled).
- Actual private Google Sheet ID → `REPLACE_WITH_TEST_SHEET_ID`.
- OAuth credential identifiers, secrets, tokens and saved credential objects → not included.
- Node identifiers → newly generated, synthetic IDs for exported examples.
- Legacy archived workflow and **original private repository history** → not included.
- Live Forms, CVs, candidate records and editable Google URLs → not included.

## Before enabling any Gmail node

1. Only configure your *own* test spreadsheet filled with synthetic data.
2. Confirm all three Gmail `To` addresses are an inbox you control. Do not use applicant-derived email expressions.
3. Execute manually, one branch at a time. Keep the workflow inactive.
4. Never commit screenshots showing account identities, credentials, sheet IDs, browser tabs, or real applicant details.

**Scope of review:** A static scan for obvious identifiers/secrets, examination of the exported node types and fields, and visual inspection of the supplied screenshot. This is **not** a penetration test, a legal/IP clearance review, or proof that a future user cannot misconfigure a workflow. The public package contains no inherited history; *after* creating a new GitHub repository, review its visibility, contents and first commit before sharing its link.

## Responsible use

Experience-based branching in this demonstration is **not an applicant evaluation system**. Do not use these demo invitation or keep-on-file messages to make real candidate decisions. Build a human-reviewed, privacy-conscious process for any genuine recruitment operations.
